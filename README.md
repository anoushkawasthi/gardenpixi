# The Pixel Garden

Personal portfolio — **The Pixel Garden** — per PRD v1.2 / TRD v1.0.

## Docs

- [Implementation plan](.docs/IMPLEMENTATION_PLAN.md) — phased delivery
- [Dependencies & setup](.docs/DEPENDENCIES_AND_SETUP.md) — install, env, scripts

## Quick start

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` when implementing EmailJS (contact form).

## Stack

React 18, Vite 5, TypeScript 5, Tailwind CSS v4, Zustand, Zod (projects content), PixiJS v8, Framer Motion, GSAP, `@fontsource/dm-sans`, `@emailjs/browser` — see `.docs/DEPENDENCIES_AND_SETUP.md`.
